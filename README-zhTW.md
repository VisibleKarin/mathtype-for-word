# MathType for Word

面向 Word 公式處理的個人改進版本。

## 改進內容

- 設定選定公式的內部 Full 字號，並在儲存後讀回核驗。
- 局部替換公式，同步預覽、尺寸和基線，保留相鄰文字、軟換行、批註及原生編號引用。
- 比較數學結構，協助發現內容重複追加、上下標層級變化等問題。
- 普通 Word 變數和上下標可保留文字形式，不強制轉換為公式物件。
