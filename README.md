# MathType for Word

面向 Word 公式处理的个人改进版本。

## 改进内容

- 设置选定公式的内部 Full 字号，并在保存后读回核验。
- 局部替换公式，同步预览、尺寸和基线，保留相邻文字、软回车、批注及原生编号引用。
- 比较数学结构，帮助发现内容重复追加、上下标层级变化等问题。
- 普通 Word 变量和上下标可保留文字形式，不强制转换为公式对象。
